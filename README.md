# Study Buddy Web App

A web application that connects students with study partners based on shared courses.

## Overview

Study Buddy helps students find and coordinate with classmates for course-specific study groups. Users can create accounts, join or form study groups, and match with others taking the same courses.

## Tech Stack

- **Backend:** Python, Flask
- **Database:** PostgreSQL
- **Frontend:** HTML, CSS, jQuery (JavaScript)

## Features

- User account management
- Study group creation and management
- Course-based matching between students

## Status

Actively developed as part of a Web Applications project at East Carolina University.
